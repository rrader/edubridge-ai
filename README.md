# EduBridge AI

Навчальна PWA для математики 6 класу: дроби, пояснювані адаптивні режими та локальний поступ. Проєкт демонструє, як цифровий помічник може підтримати самостійну роботу, а невирішені труднощі передати вчителю.

## Запуск

Потрібен Node.js 22 або сумісний LTS.

```bash
npm ci
npm run dev
```

Production build і тести:

```bash
npm test
npm run build
npm run test:e2e # потребує встановленого Playwright Firefox
```

Відкрий локальний URL, який покаже Vite. PWA і Browser AI працюють лише через HTTPS або `localhost`. Щоб перевірити production-подібний запуск: `npm run preview`.

## Навчальні режими

- **Самостійне навчання:** курс і математична перевірка працюють без AI.
- **Адаптивне навчання:** повторна помилка чи виявлена типова хиба дає інше пояснення.
- **Потрібна допомога вчителя:** після трьох невдалих адаптивних втручань записується локальний запит з навчальними доказами.

Спробуй чотири відтворювані демонстрації з оглядової сторінки. Кожну позначено як симуляцію; вона не створює фальшивих вимірювань.

## AI та приватність

Автоматичний режим використовує налаштований OpenAI-сумісний Chat Completions endpoint, потім готову WebLLM модель, інакше — окремо позначені перевірені пояснення курсу. API key із налаштувань існує лише у стані відкритої вкладки. Це режим розробки: не додавай секрет у frontend і не використовуй його як production-захист. Для спільного використання налаштуй власний захищений proxy.

WebLLM: `Qwen2.5-0.5B-Instruct-q4f16_1-MLC`. Завантаження близько 945 МБ; потрібна значно більша доступна пам’ять GPU. Модель і runtime підтягуються лише після натискання на сторінці офлайн-підготовки. Деталі й обмеження — у [`docs/OFFLINE_MODE.md`](docs/OFFLINE_MODE.md).

Профілі, відповіді, історія та запити зберігаються в IndexedDB цього браузера. Хмарі надсилається тільки явне запитання у відкритому чаті та короткий контекст уроку; історія учня не додається.

## GitHub Pages

GitHub Actions публікує окремий Pages сайт цього репозиторію: `https://rrader.github.io/edubridge-ai/`. Застосунок збирається з базовим шляхом `/edubridge-ai/`.

GitHub Pages для проєктного репозиторію не прив’язує його автоматично до `https://rmn.pp.ua/edubridge-ai/`. Такий підшлях потребує маршрутизації у власника кореневого домену (наприклад, конфігурації основного сайту чи проксі). У цьому проєкті такі зовнішні налаштування не змінюються.

## Про внесок

WebLLM, Qwen і React — сторонні бібліотеки/модель. Код навчального state machine, дробової перевірки, локальних intervention-запитів, курсу та сценаріїв — код EduBridge. Команда має оцінити педагогічну якість з учителями та учнями; короткий автоматичний тест не доводить навчальний ефект.

# Офлайн режим і браузерна модель

## Що кешується

Service worker, створений vite-plugin-pwa, попередньо кешує HTML, JavaScript, CSS, локальний SVG та JSON. Dexie тримає вправи/поступ у IndexedDB. Це окремо від моделі: натискання «Завантажити офлайн-модель» запускає WebLLM і дозволяє його кешувальнику отримати модельні ваги. Після ініціалізації застосунок робить тестовий запит українською. Інференс відбувається локально, без LLM API.

Сторінка запитує persistent storage, показує WebGPU та сховище, і попереджає, що браузер може очистити дані. Модель не завантажується автоматично. Якщо WebGPU несумісний, курс і вправи лишаються працездатними.

## Обрана модель

- Model ID у WebLLM: `Qwen2.5-0.5B-Instruct-q4f16_1-MLC`.
- Орієнтир завантаження: приблизно 945 МБ для готового WebLLM варіанту. Точний кеш/перенесення може змінитися разом з версією runtime.
- Пам’ять: потрібен запас понад розмір файлів для GPU буферів, runtime та контексту; практична межа залежить від пристрою. UI рекомендує 1,3 ГБ вільного browser storage, але це не гарантує достатньої VRAM.
- Сумісність: актуальний браузер із WebGPU (наприклад, Chromium-based браузери на сумісному GPU); Safari/Firefox підтримка та драйвери залежать від конкретних релізів/платформи. EduBridge має визначати API `navigator.gpu` і перевірити реальну ініціалізацію.
- Мова: Qwen2.5 підтримує багатомовний ввід і може відповідати українською, але 0.5B модель має обмежене міркування, термінологію та стабільність. Відповіді не є перевіреним курсом; тест базового пояснення в коді перевіряє запуск, але не якість української.
- Ліцензія базових Qwen2.5 ваг: Apache-2.0; WebLLM/runtime має власну ліцензію/залежності, їх слід перевірити для релізу.

Посилання на першоджерела: [WebLLM](https://github.com/mlc-ai/web-llm), [Qwen2.5-0.5B-Instruct](https://huggingface.co/Qwen/Qwen2.5-0.5B-Instruct), [WebLLM model config](https://github.com/mlc-ai/web-llm/blob/main/src/config.ts).

## Перевірка

Реальний офлайн тест: завантажити модель, дочекатись готовності, вимкнути мережу в ОС/браузері, перезавантажити сторінку, пройти вправу, закрити й повторно відкрити вкладку, поставити питання локальній моделі. Playwright тест, який блокує віддалені URL, перевіряє тільки локальний навчальний контент; це не доказ доступності кешу моделі чи повного офлайн-перезапуску. Поки модель не запускалась на конкретному GPU, readiness не можна називати перевіреним.

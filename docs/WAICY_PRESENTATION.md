# План презентації WAICY

1. **Проблема:** нерівний доступ до вчителів і нестабільний інтернет; SDG 4.1, 4.5 та SDG 10.
2. **Демо:** самостійно пройти вправу про дріб і показати незалежну математичну перевірку.
3. **Внесок:** пояснювана state machine вирішує, коли змінити пояснення, а коли покликати людину.
4. **Режим адаптації:** повторити вправу з помилковим додаванням знаменників; показати виявлену хибу й простіший крок.
5. **Вчитель:** подивитися локальний запит із помилкою і спробами підтримки.
6. **Offline-first:** підготувати браузерний кеш заздалегідь; перевірити вправи без мережі на підготовленому пристрої.
7. **Обмеження:** Qwen є сторонньою моделлю, локальний малий LLM може помилятися, курсові відповіді перевіряє математика, синхронізації немає.
8. **Дослідження:** описати протокол та людську рубрику; показувати лише виміряні наявні результати.

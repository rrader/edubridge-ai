# Посібник для команди учнів

## Де працювати

- `src/curriculum.ts` — теми, цілі, пояснення, приклади й вправи.
- `src/learning/fractions.ts` — точна перевірка раціональних чисел та типові помилки.
- `src/learning/stateMachine.ts` — переходи між трьома режимами.
- `src/ai.ts` — спільний API та три провайдери.
- `src/storage.ts` — IndexedDB та експорт/імпорт.
- `src/App.tsx` і `src/App.css` — екрани та взаємодія.

## Безпечні зміни

1. Зміни одну невелику частину.
2. Додай приклад/тест, який спростовує помилкову поведінку.
3. Запусти `npm test` і `npm run build`.
4. Перевір UI руками у Firefox або іншому дозволеному браузері.
5. Для математики перевір еквівалентні дроби, нуль і некоректний знаменник.

Не додавай персональні дані школярів до демо, не надсилай журнал у хмару, не додавай API секрет у код. Власна розробка команди — це навчальна логіка і експеримент, не сторонні pretrained weights.

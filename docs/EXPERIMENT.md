# Протокол експерименту

## Мета

Порівняти на тих самих 20 українських навчальних запитаннях (панель «Оцінювання») Cloud AI, Browser AI і детермінований навчальний курс. У MVP зібрані запитання, експорт CSV спроб і рубрика людського перегляду. Вимірювання не створюються наперед.

## Метрики

Фактичні спроби/точність з `attempts`; кількість переходів між режимами з `history`; адаптивні втручання та ескалації з `requests`; використаний провайдер; час відповіді можна вимірювати у майбутній версії. Ініціалізація WebGPU та offline readiness записувати лише після реального клієнтського заміру. Вільне сховище фіксувати через Storage API разом із моделлю/браузером.

## Процедура

1. Зафіксувати версію EduBridge, браузер, ОС, GPU, браузерні версії та умови мережі.
2. Виконати кожне контрольне запитання кожним доступним провайдером з однаковим контекстом уроку.
3. Для математичних тверджень автоматично перевірити результат раціональними правилами.
4. Двоє рецензентів незалежно оцінюють пояснення за 1–4: математична правильність, ясність української, навідність, вікова доречність, визнання невизначеності. Обговорити розбіжності окремо.
5. Експортувати CSV фактичних вправ; не змішувати з демонстраційними симуляціями.

Не робити висновок про педагогічну ефективність із короткого тесту чи думки моделі. Тут не наведено жодних вигаданих результатів.
